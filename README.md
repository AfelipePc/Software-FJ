
# Sistema de Gestion Software FJ

## Descripcion del proyecto

Software FJ es un sistema desarrollado en Python para gestionar clientes, servicios y reservas de una empresa dedicada a ofrecer servicios tecnologicos.

El proyecto utiliza programacion orientada a objetos para organizar la informacion y facilitar el control de las operaciones.

## Objetivo

Desarrollar un sistema que permita administrar clientes, gestionar servicios y registrar reservas, aplicando conceptos fundamentales de programacion orientada a objetos y manejo de excepciones.

## Servicios disponibles

- Reserva de salas.
- Alquiler de equipos.
- Asesorias especializadas.

## Funcionalidades

- Registro y consulta de clientes.
- Validacion de datos.
- Gestion de servicios.
- Creacion y consulta de reservas.
- Confirmacion y cancelacion de reservas.
- Calculo de costos.
- Manejo de excepciones.
- Registro de eventos y errores mediante logs.

## Tecnologias utilizadas

- Lenguaje de programacion Python.
- Programacion orientada a objetos.
- GitHub para el almacenamiento del codigo fuente.

## Estructura del proyecto

- main.py: programa principal y menu del sistema.
- entidades.py: clase base abstracta.
- clientes.py: gestion de clientes.
- servicios.py: clases y tipos de servicios.
- reservas.py: gestion de reservas.
- excepciones.py: excepciones personalizadas.
- registro_logs.py: registro de eventos y errores.
- logs/: carpeta donde se almacenan los registros generados.

## Ejecucion

Para ejecutar el sistema desde una terminal con Python instalado, utiliza:

python main.py
